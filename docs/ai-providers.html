PocketCane AI Providers

Last updated: October 7, 2026

These services receive data only when you allow photo sharing and request an AI description. Camera and LiDAR feedback stay on your device.

Current Recipients

  • OpenRouter, Inc. routes the JPEG photo and description instructions to the model host and returns the result. See OpenRouter’s privacy policy and data collection information. OpenRouter records operational request metadata. Its documentation says storing inputs and outputs is opt-in.
  • ByteDance Seed hosts the Seed 2.0 Lite model that produces the description. The app selects the Seed endpoint and does not fall back to other hosts. OpenRouter currently lists Seed as not training on prompts and as having zero prompt retention. See the provider directory for Seed’s current service terms and privacy links. These statements concern request content, not a guarantee that no billing, security or legally required records exist.

Provider Changes

This list covers the app version released with it; older versions may use the recipients disclosed in those versions. We update this list and the app’s disclosure before changing recipients. You will be asked for permission again when recipients or material processing practices change. A model change within the same disclosed services does not, by itself, change the categories of data shared.
